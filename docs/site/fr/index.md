# SKRAFT en 15 minutes

SKRAFT est un pipeline SDLC piloté par des agents IA spécialisés. Chaque phase du cycle de développement est exécutée par un agent dédié, puis validée par un reviewer indépendant — aucun agent ne valide son propre travail.

> « Programs must be written for people to read, and only incidentally for machines to execute. »
> — Abelson, H. & Sussman, G. J., *Structure and Interpretation of Computer Programs*, 1985.

## Les 5 phases

1. **DISCOVER** — Le backlog-discoverer trie et priorise les issues pour produire un rapport de triage.
2. **DISCUSS** — Le backlog-planner affine les stories selon les critères INVEST et produit des critères d'acceptation.
3. **DESIGN** — Le solution-architect modélise l'architecture via Event Modeling, DDD et ADR.
4. **DISTILL** — L'acceptance-designer traduit les décisions d'architecture en scénarios Gherkin exécutables.
5. **DELIVER** — Le software-engineer implémente le code via Outside-In TDD avec Mutation Score comme garde-fou qualité.
