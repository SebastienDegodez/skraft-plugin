# SKRAFT in 15 minutes

SKRAFT is an AI-agent-driven SDLC pipeline. Each development phase is executed by a dedicated agent, then validated by an independent reviewer — no agent verifies its own work.

> « Programs must be written for people to read, and only incidentally for machines to execute. »
> — Abelson, H. & Sussman, G. J., *Structure and Interpretation of Computer Programs*, 1985.

## The 5 phases

1. **DISCOVER** — The backlog-discoverer triages and prioritises issues, producing a triage report.
2. **DISCUSS** — The backlog-planner refines stories against INVEST criteria and produces acceptance criteria.
3. **DESIGN** — The solution-architect models architecture via Event Modeling, DDD, and ADRs.
4. **DISTILL** — The acceptance-designer translates architecture decisions into executable Gherkin scenarios.
5. **DELIVER** — The software-engineer implements code via Outside-In TDD with Mutation Score as a quality gate.
