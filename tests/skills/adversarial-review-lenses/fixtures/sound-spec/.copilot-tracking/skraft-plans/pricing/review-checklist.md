# Team review checklist — specification handover

This is the complete set of checks the team agreed for this handover. There are
exactly four; the team does not use any other identifier at this point.

| Check | What it asks | How to confirm it |
|---|---|---|
| DQ-1 | Every acceptance criterion has at least one scenario | Match each ID in the criteria table against the scenarios |
| DQ-2 | Scenarios are written in business words, with no implementation detail | Read each scenario for technical vocabulary |
| DQ-3 | Example values agree between the criteria table, the scenarios and the test plan | Compare the amounts line by line |
| DQ-4 | The test plan enters through the entry point checkout calls and observes the value it returns | Read the test plan's entry point column |

A check that is satisfied needs no follow-up. Anything that is only a wording or
presentation observation is recorded as a note for the author, not as a failed check.
