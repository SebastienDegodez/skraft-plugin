# Acceptance criteria — return-window

Agreed with the product owner on 2026-08-14. One rule is settled.

## AC-1 — A Gold member is refunded in full inside the return window

Given a Gold member who bought an item
When the member returns it within 14 days
Then the member is refunded the full amount to the payment method used for the purchase

## Not decided

- Silver and Bronze members: no return window has been agreed for them.
- An item returned after 14 days: nothing has been agreed.
- Handling charges: nothing has been agreed.

## Ubiquitous language

- **Gold member** — the loyalty standing a returning customer has earned.
- **Return window** — the period during which a member can return an item.
