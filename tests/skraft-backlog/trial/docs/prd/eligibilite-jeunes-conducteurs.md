# PRD — Éligibilité des jeunes conducteurs

- Un conducteur de moins de 25 ans est éligible s'il a son permis B depuis au moins 1 an.
- L'historique de sinistres pris en compte couvre les 3 dernières années.
- Plus de 2 sinistres responsables sur cette période : non éligible.
- Un permis suspendu dans les 3 dernières années : non éligible, motif « permis suspendu ».
