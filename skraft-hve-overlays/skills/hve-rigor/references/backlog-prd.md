## ADO Backlog Manager

### MANDATORY

* Load `issue-triage` skill.

### OPTIONAL

* Before refining a raw request into a user story: Load `issue-refinement` skill.
* Before finalizing a ready handoff: Load `planning-review-criteria` skill.
* For sprint or iteration planning: Load `sprint-planning` skill.
