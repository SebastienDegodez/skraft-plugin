# PRD route

Use for PRD Builder, meeting-to-PRD handoffs, PRD session state, PRD documents,
and PRD-derived work-item hierarchies.

## Skill Loading — MANDATORY

Load each skill before starting PRD work. Only announce missing ones:
`[SKILL MISSING] {skill-name}`. A missing skill blocks PRD completion.

### Always load for this route

* `issue-refinement`

### Load on demand (trigger-based)

None.

Require testable functional requirements, measurable non-functional
requirements, stable requirement identifiers, and traceability. Block
ambiguous, untestable, unmeasurable, or solution-disguised requirements.
