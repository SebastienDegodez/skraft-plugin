## Task Implementor

### MANDATORY

* Load `outside-in-tdd` skill.
* Load `red-synthesize-green` skill.
* Load `craft-discipline` skill.
* Load `resolving-stack-commands` skill.

### OPTIONAL

* When choosing test levels, boundaries, or doubles: Load `clean-architecture-testing` skill.
* After GREEN, when refactoring tests: Load `test-refactoring-catalog` skill.
* During commit and verification: Load `mutation-testing` skill.
* During commit and verification: Load `quality-gates-evidence-contract` skill.
* When the repository is .NET: Load `quality-gates-dotnet` skill.
* When mocking a downstream HTTP or event dependency: Load `mocking-strategy-roster` skill.
* When implementing an API or provider contract test: Load `contract-testing` skill.
* When capturing E2E UI evidence: Load `playwright-evidence` skill.
