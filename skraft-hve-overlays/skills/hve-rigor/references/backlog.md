# Backlog route

Use for ADO, GitHub, or Jira backlog discovery, triage, refinement, sprint
planning, PRD-to-work-item planning, and execution artifacts.

## Skill Loading — MANDATORY

Load each skill before starting backlog work. Only announce missing ones:
`[SKILL MISSING] {skill-name}`. A missing skill blocks backlog readiness.

### Always load for this route

* `issue-refinement` for INVEST, Definition of Ready, splitting, and
  antipatterns
* `issue-triage` for type, priority, effort, and duplicate classification
* `planning-review-criteria` for acceptance criteria and planning gates

### Load on demand (trigger-based)

None.

Do not mark an item ready while an INVEST dimension, Definition of Ready item,
triage classification, or planning gate is missing.
